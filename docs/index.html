Text Rectangle Generator

Generate STL: rectangular plate with raised text. Text is scaled to fit the rectangle; thickness and letter height are parametrized. Arial Bold style when font is loaded.

Generator

Set rectangle size (mm), plate thickness, letter height, and text. Output: STL for 3D printing.

Output
Set parameters and click Generate to create plate STL.

About

Parameters match the CLI JSON. Use npm run build-web and deploy docs/ for GitHub Pages. Font: load Arial Bold (or similar) via font URL for best results; otherwise built-in vector font is used.
